# Political Engine 0.6.3

Experimental SkyrimNet political correspondence, diplomacy, economy and campaign.
This continues Political Letters v2.41 with save-compatible technical identities.

## Downloads

1. `PoliticalEngine-v0.6.3-beta25.zip` — install first.
2. `PoliticalEngine-v0.6.3-Russian-patch.zip` — optional Russian UI; install second.

Built for Skyrim SE 1.6.1170 / SkyrimNet Beta25. See README for dependencies.
The name stays Political Engine in Russian; letter language remains prompt-controlled.

## Updating

Replace the old installation. Retain `PoliticalLetters.esp`, its original load
position and legacy files. Do not save while the mod is removed, rename files,
clean the save or enable two installations. Back up `.ess` and matching `.skse`.

## Changes

New branding, tabbed regional UI, resource indicators, buildings and NPC
construction, negotiated NPC trade routes, full correspondence history and
first-run relationship assessment. Includes current v2.41 fixes.

## Verification and limitations

220 offline tests and browser checks passed. In-game compatibility still requires
testing. This is an experimental release, not a guarantee against mod conflicts.
Trade routes are schematic; no physical caravans. No NPC-versus-NPC wars.
